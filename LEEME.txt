SITIO WEB — Remote & Partners
La ciudad flotante. Todo en un solo archivo: sin dependencias,
sin carpeta de imágenes, sin servidor.

  index.html      ESTE es el que se sube al dominio.
                  Documento completo, con favicon y metadatos.
                  Se sube tal cual a public_html en cPanel.

  ciudad.html     El mismo trabajo en formato artifact (sin doctype
                  ni head). Sirve para previsualizar. Se mantiene
                  sincronizado con index.html.

  ciudad-bn.html  Versiones anteriores, guardadas por si acaso.
  ciudad-*.png    Ya no se usan.
  *.part          Descargas a medias. Se pueden borrar.

PARA PUBLICAR EN remoteandpartners.com
El dominio corre WordPress en BanaHosting. Los pasos, y el porqué
de cada uno, están explicados aparte. Resumen:
  1. cPanel -> File Manager -> public_html
  2. Subir index.html a una carpeta /ciudad para probarlo
  3. Cuando convenza, moverlo a la raíz y añadir al .htaccess,
     antes de "# BEGIN WordPress":  DirectoryIndex index.html index.php
  4. Enlazar las páginas legales, que hoy quedarían sin acceso
